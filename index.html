NodeAi

Una mesa redonda de IAs en una interfaz simple, actual y personalizable.

Concepto y Estructura

NodeAi es una aplicación de escritorio desarrollada en Flet (código abierto). En lugar de un chat tradicional, plantea una mesa redonda de hasta 20 IAs que conversan en paralelo, lideradas por un modelo "Director" encargado de sintetizar la respuesta final.

El Logo como Indicador

El logotipo no es estático; funciona como un indicador visual de actividad. Está formado por un círculo central rodeado de 20 círculos periféricos. Cada asiento se enciende cuando una IA de la mesa está respondiendo y parpadea suavemente cuando un modelo está pensando.

Modo Agente y Control

Debajo del botón de encendido se puede activar el Modo Agente. Este modo permite asignar tareas de pasos limitados o ilimitados, otorgándole al modelo Director la capacidad de ver la pantalla y controlar el teclado y ratón del PC, siempre bajo niveles de aprobación configurables.

Interfaz y Seguridad

  • Diseño Actual: Estética inspirada en Gemini o Claude, con mucho aire visual y personalización de temas (Claro/Oscuro/Alto contraste).
  • Privacidad Primero: Las API keys no se guardan automáticamente; existe una opción para guardarlas acompañada de un aviso de que residirán en texto plano.
  • Biblioteca Integrada: Los modelos, roles y prompts se manejan desde archivos JSON versionados, accesibles y configurables desde la misma app.
